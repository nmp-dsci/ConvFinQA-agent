s16 · branch ui-migration · 2026-09-29 · plan for review, nothing built

ConvFinQA moves to the house UI in blue, and the house UI becomes a kit that every project pulls from.

DataAgentBench (green) and tau2-loop (red) already share one app: the site's Field Guide tokens, a sticky header with eight pill-shaped tabs, and plain CSS with no framework. ConvFinQA is a different app, "The Console": dark-first, Tailwind + shadcn, a left rail, amber. This plan ports ConvFinQA onto the house UI. As it does, it carves the shared parts into nmp-central-ai/ui/, with a platform-ui skill to stand up a new agent UI and a make ui-sync to bring every project up to the latest kit.

3 · Blue — a deep ink-blue that clears contrast as well as the red does

The blue matches the green and red for weight: dark enough to carry white text in light mode, and light enough to read on the near-black panels in dark. The ratios below were computed with the site's own contrast_audit.py functions (WCAG 2.x).

   not from here: every project gets the same status pair. */

What the rest of the palette does

  • Status becomes kit-standard. tau2-loop added --ok because its accent is red, and DataAgentBench added --red because it needed "failed". The kit defines both for everyone, so a pass is always green and a fail always red, whatever the brand.
  • --info goes. It is already blue (#1d54ab light), so it would read as "act on this". Informational lamps become neutral --ink-2 with a glyph and a word.
  • --violet goes. The brief says "no purple". The SDK stage colour becomes a word label.
  • --amber keeps its name but changes meaning, from "the CTA" to "partial / caveat". That is the one rename a find-and-replace gets wrong, so C0 bridges it by hand.

5 · The port — keep the machinery, replace every pixel

"Exactly the same tabs and feel" rules out a restyle inside Tailwind: the siblings share CSS classes, not utility strings. The behaviour libraries are invisible, though, and ConvFinQA's chat, SSE stream and tables depend on them, so they stay. They get restyled with kit classes.

DependencyVerdictWhy
react-query · zustand · fetch-event-source · TanStack Table (headless)keepLogic, not look. Chat's SSE and the store's 513 lines stay as they are. TanStack sorting renders into kit th.sortable tables.
radix Dialog / Sheet · cmdkkeep, restyleFocus traps and a11y are hard to rebuild. The report picker and drawers get kit panel CSS. The palette depends on Q5/batch item B-2.
tailwindcss · @tailwindcss/vite · tw-animate-css · cva · tailwind-merge · components.jsonremove (C5)They conflict with the kit's CSS. Removed only after the last page is ported, and a grep for utility classes has to come back empty.
lucide-react · rechartsremoveIcons become glyphs and words; SliceChart becomes a .dia SVG bar chart, as the siblings draw.
@fontsource Plex Sans + Monokeep, add SerifSelf-hosting suits the demo container. The site self-hosts too; the siblings use Google Fonts. The kit allows either.
Test IDs are frozen. Every data-testid the e2e specs and demo_smoke.sh read (landing-board, readiness-strip, judge-badge, composer-run-all and the rest) is kept through the port. Only nav.test.tsx is rewritten; it becomes the kit's routes.test.tsx.

6 · The kit — nmp-central-ai/ui/, vendored into each app, checked for drift

Today the style spreads by copy: DataAgentBench → tau2-loop, and the copy has already drifted (lib/ui.tsx has 102 changed lines out of about 95). A third copy would triple that; this is the point to stop copying. Its migration produces the kit as it goes, and everything later pulls from the kit.

# skill: platform-ui — "stand up an agent UI", "match the house
# style", "update this project to the latest UI", "new project colour"

Vendored, not an npm package, because every app builds in Docker from its own repo, and a file:../nmp-central-ai dependency breaks that build and CI. The drift check gives the "one place to update" property without coupling the builds (decision Q4). The site's tokens.css stays the palette origin, and ui-check asserts that tokens.base.css still equals it minus the accent.

9 · Risks — the port is large; the one real unknown is Chat's layout

IDRiskMitigation
R-1Scope. 18k lines, 2.7× the size of DataAgentBench. A literal page-by-page rewrite is weeks.The token bridge gets the look right at C0; C1 gets the tabs. After that each page is ported one PR at a time, and the app is shippable after every phase. Q1 sets how deep this goes.
R-2Chat does not fit a 1,140px column. It has three panes plus an Inspector (240–560px, drag-resizable). The siblings have no full-height app page.The kit gains main.app: full width, full height below the header, same tokens. It is the first kit extension that ConvFinQA contributes, and tau2-loop's Agent playground can use it too.
R-3Route renames reach the public demo, README links and the portfolio's front matter.Redirect loaders for every old address, pinned by routes.test. readiness.problems() catches a stale link in CI.
R-4Colour meaning shifts. amber goes from CTA to caveat; --info would read as the accent; --violet goes.Mapped by hand in C0, not by find-and-replace. Status always carries a word and a glyph, so no meaning rides on hue alone.
R-5Dark-first → OS-first. A visitor on a light OS sees a light app for the first time.Intended: light is the Field Guide's reference palette. Q5 decides whether a toggle survives.
R-6The central plan says "frontends are never centralised" (nmp-central-ai/ai_specs/s00_project_plan.md:25).D25 amends it narrowly: the kit is central, and each frontend stays in its own repo and its own build. The "duplication count ≥ 2" rule is met: DataAgentBench and tau2-loop, with ConvFinQA the third.
R-7Kit churn during C0–C5. ConvFinQA would consume a kit that is still moving.v0.1 is vendored and pinned. v1.0 is cut at K1 from what the port learned, and only then synced to the siblings.
